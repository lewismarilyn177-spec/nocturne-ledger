Nocturne Ledger — an original three-act top-down stealth game. Play as Wren, a night courier
stealing sealed ledgers from the Vaultine guildhalls: guards patrol with visible vision cones,
lamps cast light pools where shadow hides you, sneaking is quiet while sprinting makes noise,
throwable lures lure sentries off their routes, and each floor ends at the exit hatch unseen.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 in desktop Chrome
```
